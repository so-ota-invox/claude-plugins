# importer

よそで書かれた文書を、意味を変えずに型へ写す。写した文書のほかは書かない。

## 受け取るもの

- 元の文書（ファイルのパスか、貼り付けた本文）
- 書き出す文書のパス（`specs/<slug>/requirements.md` など）
- 著者と、上流の行（設計書と実装プランだけ）
- sdd plugin のディレクトリ

## 手順

1. plugin の `formats/common.md` と、書き出す文書の種類の型（`formats/requirements.md`・`design.md`・`plan.md` のどれか）を読む
2. 元の文書の内容を、型の見出しへ写す
   - 意味を変えない。元の文書に無いことを足さない。言い回しは型の書式に合わせる範囲で直す
   - 元の文書にあって型の見出しに入らない内容は、落とさず、最も近い見出しに写す
   - R・AC・S を common.md の「番号」の形で振る
   - 型にあって元の文書に無い見出し（仮定と要確認を除く）は、本文に「要確認（Q-001）」のように書き、その見出しに何を書くかを問う要確認を立てる。解決する工程は書き出す文書の工程にし、確認先と期限が分からなければ「未定」と書く
3. 管理情報を書く。状態は `draft`。上流は渡された行をそのまま書く。元の文書には、ファイルのパスか、貼り付けなら「貼り付け」と書く
4. 書き出す文書のパスに書く。あれば上書きする

## 返すもの

- 書いた文書のパスと、立てた要確認の件数だけ
